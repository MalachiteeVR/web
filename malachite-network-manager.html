MalachiteVR Network Manager

A Windows-first desktop network manager built in Rust. Manage adapters, inspect TCP connections, work with Windows Defender Firewall, and discover and configure UPnP port mappings from one native-feeling interface.

Download / Releases View Source
v0.2.0 is the current release line.
The project is open source and currently targets Windows. The application uses Rust for its native shell and Microsoft Edge WebView2 for its interface.

Network adapters

  • Native Windows adapter enumeration
  • Link speed and operational status
  • MAC address display
  • Enable or disable adapters

Connections & addressing

  • Current TCP connection viewer
  • Local and remote IPv4 endpoints
  • Connection state and owning PID
  • Private IPv4 detection

Windows Firewall

  • List Windows Defender Firewall rules
  • Create firewall rules
  • Remove firewall rules
  • Native Windows Firewall COM API

UPnP port mapping

  • SSDP Internet Gateway discovery
  • Inspect existing port mappings
  • Add TCP and UDP mappings
  • Maps to the detected private IPv4 address

Built with native Windows APIs

Network and firewall operations are implemented through Windows APIs rather than spawning PowerShell commands. Work is performed asynchronously so discovery and firewall enumeration do not freeze the WebView interface.

Rust · Windows IP Helper API · Windows Firewall COM · SSDP / UPnP · Wry · Microsoft Edge WebView2
Requirements: Windows with a supported Microsoft Edge WebView2 Runtime installation. Administrator privileges are requested because adapter and firewall changes require elevation. See the project's README for build instructions and security notes.
